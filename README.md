# مغز مصنوعی 🧠

ربات تلگرامی که کد خودش (`bot.php`) را با کمک هوش مصنوعی (OpenRouter) توسعه می‌دهد و باگ‌هایش را رفع می‌کند.

> این پروژه قبلاً با نام «پسرم فرهاد» شناخته می‌شد و منطق و قابلیت‌هایش دقیقاً همان است؛ فقط نام و روش نگه‌داری کلیدها (برای امنیت روی گیت‌هاب) به‌روزرسانی شده.

## ساختار فایل‌ها

| فایل | کاربرد |
|---|---|
| `config.php` | تنظیمات مرکزی؛ کلیدها را از Environment Variables می‌خواند |
| `bot.php` | فایل اصلی ربات کاربران (تلگرام وبهوک این فایل را صدا می‌زند) |
| `farhad.php` | «مغز» ربات؛ فقط پیام‌های مالک را می‌خواند و `bot.php` را اصلاح/توسعه می‌دهد |
| `router.php` | مسیریابی برای سرور داخلی PHP روی Railway |
| `Procfile` | دستور اجرای سرویس روی Railway |

## ۱) آپلود روی GitHub

```bash
git init
git add .
git commit -m "مغز مصنوعی - نسخه اولیه"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```

⚠️ **مهم:** فایل `.env` و `error_log` عمداً در `.gitignore` قرار گرفته‌اند تا هرگز روی گیت‌هاب آپلود نشوند. کلیدهای واقعی را فقط داخل Railway (مرحله بعد) وارد کنید، نه داخل کد.

## ۲) دیپلوی روی Railway

1. وارد [railway.app](https://railway.app) شوید → **New Project** → **Deploy from GitHub repo** → ریپوی بالا را انتخاب کنید.
2. Railway به‌طور خودکار `composer.json` را تشخیص می‌دهد و پروژه را به‌عنوان PHP می‌سازد.
3. به تب **Variables** بروید و این سه مقدار را اضافه کنید:
   - `TELEGRAM_BOT_TOKEN` → توکن ربات از @BotFather
   - `OPENROUTER_KEY` → کلید API از [openrouter.ai](https://openrouter.ai)
   - `OWNER_ID` → آی‌دی عددی تلگرام شما (با @userinfobot بگیرید)
4. در تب **Settings → Networking** روی **Generate Domain** بزنید تا یک دامنه عمومی (مثلاً `xxxx.up.railway.app`) بگیرید.

## ۳) ست کردن Webhook تلگرام

نکته‌ی مهم: فایل `farhad.php` در انتهای خودش فایل `bot.php` را هم include می‌کند؛ یعنی **فقط یک Webhook کافی است** و باید روی `farhad.php` تنظیم شود (نه `bot.php`). این‌طوری هم پیام‌های شما (مالک) برای توسعه‌ی ربات پردازش می‌شود و هم پیام‌های کاربران عادی توسط `bot.php` مدیریت می‌شود.

بعد از گرفتن دامنه، این آدرس را در مرورگر باز کنید (به‌جای مقادیر داخل `<>` مقادیر خودتان را بگذارید):

```
https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook?url=https://<YOUR-RAILWAY-DOMAIN>/farhad.php
```

اگر پاسخ `"ok":true` گرفتید، ربات آماده‌ی دریافت پیام است.

## ۴) استفاده از مغز مصنوعی

در تلگرام به مالک ربات پیام بدهید:

```
مغز مصنوعی یک قابلیت اضافه کن که با /start خوش‌آمد بگوید
```

یا برای رفع باگ:

```
مغز مصنوعی ربات باگ داره، اصلاحش کن
```

## نکات امنیتی

- هرگز `TELEGRAM_BOT_TOKEN` یا `OPENROUTER_KEY` را مستقیم داخل کد ننویسید؛ همیشه از Variables استفاده کنید.
- اگر توکن قبلی جایی لو رفته (مثلاً در تاریخچه‌ی گیت قبلی)، حتماً از @BotFather با دستور `/revoke` یک توکن جدید بگیرید.
- دسترسی به `farhad.php` فقط برای `OWNER_ID` باز است؛ آی‌دی خودتان را درست وارد کنید تا کس دیگری نتواند کد ربات را تغییر دهد.
